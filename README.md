# tarek-apps
Toutes les applications de Tarek réunies en un seul endroit (BES, Zwaq Deco, POD, Cafés mobiles)

## Applications

| Dossier | Application |
|---|---|
| `bes-caisse/` | BES Caisse — suivi de la caisse espèces et tableau de bord. |
| `bes-facturepro/` | BES FacturePro — devis, factures, stock et chantiers. |
| `bes-fiches-atelier/` | Fiches de meubles sur mesure, plans de débit et fiches d’atelier; comprend aussi le relevé de chantier. |
| `bes-vectorizer/` | Vectorisation d’images vers DXF, SVG et EPS pour la CNC. |
| `gestionpro/` | GestionPro Perso — suivi des finances personnelles, des projets POD et des cafés mobiles. |
| `pod-studio/` | POD Studio — recherche de niches, fiches design et préparation de livres KDP. |
| `tarek-studio/` | Espace de conception de l’outil POD de TAREK STUDIO : analyse des tendances et des designs, puis création de fiches design. |
| `zwaq-deco/` | ZWAQ DECO Publisher — outil interne pour préparer et publier le contenu des créations déco sur les réseaux sociaux; contient aussi les pages légales. |
| `zwaq-vectorizer/` | Zwaq Deco Vectorizer — conversion d’images en DXF R12 et SVG pour la CNC. |

Le code seulement : les données restent dans Supabase / Firebase, jamais dans ce dépôt (il est public).
